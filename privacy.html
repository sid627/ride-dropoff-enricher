Privacy Policy

Ride Drop-off Enricher · Last updated: August 2026

Ride Drop-off Enricher is an independent Chrome extension that enhances BlaBlaCar search results by displaying a more precise drop-off location available on the corresponding ride-detail page.

Information the extension accesses

To provide its single stated purpose, the extension may read information rendered on BlaBlaCar pages, including ride identifiers, ride URLs, destination city names, and ride drop-off addresses.

How the information is used

This information is used only to match a ride-detail page to the corresponding search result and display a more precise drop-off location to the user.

Local storage

The extension may store its enabled/disabled preference and cache ride identifiers, extracted destination addresses, and cache timestamps using Chrome extension local storage. This reduces repeated page loading and improves performance.

Data transmission and sharing

The extension does not transmit extracted ride information to any developer-operated server or analytics service. The extension does not sell, rent, or share this information with advertisers, data brokers, or unrelated third parties.

Data retention

Cached ride information is stored locally in the user's browser and is intended only as a temporary performance cache. Users can remove locally stored extension data by removing the extension or clearing the extension's stored data in Chrome.

Chrome Web Store Limited Use

The use of information accessed by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is accessed and used only as necessary to provide or improve the extension's disclosed single purpose.

Third-party service

The extension operates on BlaBlaCar webpages. Use of BlaBlaCar itself is subject to BlaBlaCar's own terms and privacy practices. Ride Drop-off Enricher is not affiliated with, endorsed by, or operated by BlaBlaCar.

Changes to this policy

This policy may be updated if the extension's functionality or data practices change. The current version will remain available at this page.
